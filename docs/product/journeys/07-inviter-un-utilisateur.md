# Parcours — Inviter un utilisateur

## Objectif

Ajouter un membre à l’organisation via une invitation e-mail.

## Prérequis

- Permission `users.invite`
- Abonnement actif

## Étapes

1. Menu **Gestion** → **Utilisateurs** (`/users`), puis **Inviter**, ou aller directement à `/users/new`.
2. Saisir l’e-mail et choisir le profil / droits.
3. Envoyer l’invitation : la personne reçoit un e-mail pour rejoindre l’organisation.

## Liens utiles

- Liste : `/users`
- Invitation : `/users/new`

## Erreurs fréquentes

- « Je ne vois pas Utilisateurs » → droit `users.read` / `users.invite` manquant, ou abonnement inactif.
