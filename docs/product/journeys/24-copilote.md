# Dicter une instruction

1. Sur n'importe quelle page, utilisez **Dicter une instruction** (ou Suivi → Copilote).
2. Enregistrez, puis arrêtez. Si le micro est bloqué, choisissez **Écrire à la place**.
3. Envoyez l'instruction. Le copilote propose un compte-rendu, un client, un devis brouillon, une note ou un rendez-vous. S'il n'est pas sûr, il le dit.
4. Corrigez le texte si besoin. Pour un devis, saisissez les prix : ils ne sont pas inventés.
5. **Enregistrer dans le CRM** applique les actions retenues. **Ignorer** n'écrit rien. Aucun e-mail n'est envoyé au client.
6. Retrouvez la dictée, la décision et les liens vers les fiches dans **Suivi → Copilote**.

Le compte-rendu confirmé est visible sur l'intervention et dans le rapport PDF.

Droit : `ai.copilot`. Enregistrer un compte-rendu demande aussi `ai.field_report` et la modification d'intervention. Les autres actions demandent le droit de la fiche concernée (client, devis, note, rendez-vous).
