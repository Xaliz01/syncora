# Parcours — Planning

## Objectif

Voir et réorganiser les interventions (jour / semaine / mois).

## Prérequis

- Permission `cases.read` (menu Planning)

## Étapes

1. Menu **Suivi** → **Planning** (`/cases/calendar`).
2. Choisir la vue (jour / semaine / mois).
3. Déplacer une intervention par glisser-déposer si autorisé.
4. Cliquer une intervention pour ouvrir le détail / le dossier associé.
5. Filtrer par équipe / technicien si les filtres sont disponibles.

## Liens utiles

- Planning : `/cases/calendar`
- Ma journée (terrain) : `/my-day`

## Notes

- Le planning est une vue calendrier ; la création d’intervention se fait souvent depuis un **dossier**.
- L’assignation porte sur un **technicien** (ou une équipe), pas sur un utilisateur. Voir [08-assigner-intervention.md](./08-assigner-intervention.md).
