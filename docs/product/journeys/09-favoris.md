# Parcours — Favoris (raccourcis)

## Objectif

Épingler des pages pour y accéder vite via la **barre de favoris** sous l’en-tête (dans Planwise, pas les favoris du navigateur).

## Prérequis

- Compte authentifié, abonnement actif (barre visible dans l’app)

## Étapes

1. Ouvrir la page à épingler (ex. Dossiers, Planning, une fiche…).
2. Cliquer l’icône **étoile (★)** dans la barre de favoris (sous le header) pour ajouter la page courante.
3. Autre méthode : **glisser** un lien depuis le menu latéral vers la barre de favoris.
4. Pour retirer : recliquer l’étoile sur la page, ou retirer le favori depuis la barre.

## Notes

- Les favoris sont des **raccourcis URL** stockés par organisation (préférence compte).
- Ce n’est **pas** une page menu dédiée : pas d’entrée « Favoris » dans le catalogue de routes.
- Ne pas confondre avec les favoris du navigateur web.

## Liens utiles

- Toute page app accessible (ex. `/`, `/cases`, `/cases/calendar`) — l’étoile agit sur la page courante.
