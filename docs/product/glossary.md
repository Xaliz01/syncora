# Glossaire Planwise

| Terme                      | Définition                                                                  |
| -------------------------- | --------------------------------------------------------------------------- |
| **Organisation**           | Locataire (entreprise) : isolation des données (`organizationId`).          |
| **Dossier**                | Affaire / chantier suivi (étapes, tâches, interventions, documents).        |
| **Modèle de dossier**      | Template d’étapes/tâches réutilisable à la création d’un dossier.           |
| **Intervention**           | Créneau terrain planifié ou réalisé (photos, signature, rapport PDF).       |
| **Ma journée**             | Liste du jour des interventions du technicien connecté.                     |
| **Planning**               | Calendrier des interventions (jour / semaine / mois).                       |
| **Client**                 | Bénéficiaire du chantier (particulier ou entreprise).                       |
| **Donneur d'ordre**        | Tiers facturé quand ce n’est pas le client chantier.                        |
| **Contrat de maintenance** | Engagement récurrent (visites à programmer / auto-plan).                    |
| **Prestation**             | Ligne catalogue pour devis / facturation.                                   |
| **Facturation**            | Suivi des dossiers à facturer + sync outil compta (Pennylane, Qonto, démo). |
| **Intégration**            | Connexion OAuth / API à un outil de facturation (une active à la fois).     |
| **Profil de permissions**  | Ensemble de droits assignables aux membres non admin.                       |
| **Favoris**                | Raccourcis URL personnalisés (barre sous le header), par organisation.      |
| **Essai / démo**           | Période d’essai ; données de démonstration injectables.                     |
